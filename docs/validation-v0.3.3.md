# v0.3.3 照片完整适配（2026-10-20）

照片新增“宽度适配”和“高度适配”，与“填满裁剪”并列。适配模式保留整张照片并等比缩放，输出宽高均受所选设备实际返回的宽高约束；另一边超限时继续缩小。预览显示实际尺寸，首张模板可批量应用模式和旋转，每张仍可调整。上传元数据使用实际文件宽高。视频保留屏幕比例裁剪及最长 10 分钟限制。

- 自动测试：32 项通过。新增覆盖 800×1280、480×480、1280×800 和奇数尺寸，横图/竖图/全景、四个旋转角度、首张模板、非法适配及视频边界。
- 实际 FFmpeg/WebP 导出：验证奇数源图、旋转后四边颜色完整保留、输出不超过设备尺寸；原裁剪模式继续通过颜色和尺寸校验。
- 实际 Tauri/WebView2 + 随包 worker + 本地 HTTP 设备测试服务：首张宽度适配、第二张高度适配，实际导出并上传 800×600 和 720×1280；检查 multipart 的 PhotoWidth/PhotoHeight 与文件一致，PhotoTitle 为空，并完成目标/全部相簿回读确认。
- 界面：19 种语言、德语最小窗口布局、实际尺寸显示、旋转与重置、适配时禁用裁剪缩放、批量预览及单张调整通过。切换到返回 480×480 的 AstroToo 后，横图适配显示 480×360，恢复裁剪显示 480×480。视频不出现照片适配按钮。

上述设备交互使用本地测试服务，没有刷写真机或改变设备配置。TimesFrame 的固件依赖及真机验收状态沿用 v0.3.2；macOS 未在本机打包验证。
