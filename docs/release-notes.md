Divoom Album v0.3.7 Windows 诊断版，支持 TimsFrame（510/511/512）与 AstroToo（530）。本次仅构建 Windows x64。

- 新增完整、持久化诊断日志：硬件/能力、控制命令与响应、HTTP 状态/耗时、缓存命中、相簿数量、转换/上传与错误堆栈，按会话及请求编号关联。
- 日志优先写入应用程序同级的 `logs` 文件夹；目录不可写时自动使用 `%APPDATA%\com.divoom.timesframe\logs`。
- 过滤连接令牌、鉴权字段及媒体内容；日志追加保存，并自动轮转保留历史。
- 修复相簿为空时“刷新相簿”无法使用的问题，支持强制重新向设备读取。
- 保留 19 种语言、设备隔离缓存、WebP 照片/视频预览图、原比例裁剪及最长 10 分钟视频。

Windows 10/11 x64，需要 WebView2。提供安装版、免安装 ZIP、源码及 SHA-256 校验文件。使用时 PC 和设备必须位于同一局域网。

复现问题后，请打包应用目录中的整个 `logs` 文件夹提供分析。此版本只增强诊断，不代表已确认 10.16.11.108 相簿为空的设备端原因。
