## Divoom Album v0.3.9 Windows 存储已满提示

- 接入 `DIVOOM_NET_COMM_DEVICE_GET_STORAGE_STATUS` 对应的 `Device/GetStorageStatus`，严格按 `Full:0/1` 读取状态。
- 设备报告已满或空间不足时，相簿、导入及裁切页显示明确警告；照片/视频上传受阻，仍可保存裁切设置。
- 提交队列、任务开始及发送前重新检查，批量过程中变满也不会继续发送后续文件；清理后可刷新状态恢复。
- 相簿列表失败不影响已满提示；未知或不支持的响应不误判为已满。警告覆盖全部 19 种语言。

本次发布 Windows x64，包含下述 v0.3.8 用户反馈改进。提供安装版、免安装 ZIP、源码与 SHA-256 校验文件。Mac 继续使用 v0.3.6 安装包；未修改或刷写设备固件。

## Divoom Album v0.3.8 Windows 用户反馈改进

- 编辑草稿、修改标记和队列保存到本地，重启后自动恢复上次设备、相簿与编辑流程。切换相簿不会取消队列，待处理及转换中的任务可恢复；结果不明的中断上传会提示先核对设备。
- 四角拖拽裁切、独立查看缩放、镜像和逐张修改标记。
- WebP 画质选择、推荐值 80、实际编码体积与设备上传限制；支持照片模糊背景、黑色、白色填充设备画布，照片/视频及封面一致。
- 自动、浅色和深色主题；19 种语言的小窗口工具布局检查通过。
- 本地文件可拖入相簿。重复源文件可跳过、同时存入或替换；先确认新文件，普通相簿仅移除旧引用，全部照片替换会永久删除旧文件及所有相簿引用。
- 显示设备照片/视频数量与容量状态；固件返回 `FreeBytes` 时显示剩余空间及按当前照片体积估算的可存张数。只返回 `Full` 的旧固件无法提供精确剩余容量。

本次构建 Windows x64，本地交付；尚未发布到 GitHub，未构建新版 macOS 安装包，未刷写真机固件。

## v0.3.7 历史说明

Divoom Album v0.3.7 Windows 诊断版，支持 TimsFrame（510/511/512）与 AstroToo（530）。本次仅构建 Windows x64。

- 新增完整、持久化诊断日志：硬件/能力、控制命令与响应、HTTP 状态/耗时、缓存命中、相簿数量、转换/上传与错误堆栈，按会话及请求编号关联。
- 日志优先写入应用程序同级的 `logs` 文件夹；目录不可写时自动使用 `%APPDATA%\com.divoom.timesframe\logs`。
- 过滤连接令牌、鉴权字段及媒体内容；日志追加保存，并自动轮转保留历史。
- 修复相簿为空时“刷新相簿”无法使用的问题，支持强制重新向设备读取。
- 保留 19 种语言、设备隔离缓存、WebP 照片/视频预览图、原比例裁剪及最长 10 分钟视频。

Windows 10/11 x64，需要 WebView2。提供安装版、免安装 ZIP、源码及 SHA-256 校验文件。使用时 PC 和设备必须位于同一局域网。

复现问题后，请打包应用目录中的整个 `logs` 文件夹提供分析。此版本只增强诊断，不代表已确认 10.16.11.108 相簿为空的设备端原因。
